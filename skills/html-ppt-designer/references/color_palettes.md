# 行业演示文稿设计方案库

本文件为不同行业的HTML演示文稿（PPT）提供了专业的设计与配色方案。在生成幻灯片时，请根据用户指定的行业，从中选择三种风格迥异的方案供用户选择。

---

## 1. 教育 (Education)

教育行业的配色通常旨在传达知识性、友好性和启发性。

### 方案一：经典学院 (Classic Academia)

该配色方案融合了深蓝色的智慧感和米色的温暖感，营造出一种经典、严谨而又不失亲和力的学术氛围。

| 用途 | 颜色 | HEX 色值 |
| :--- | :--- | :--- |
| 主色 (Primary) | 智慧蓝 | `#003366` |
| 辅助色 (Secondary) | 书卷米 | `#F5F5DC` |
| 强调色 (Accent) | 金色橡木 | `#C8A464` |
| 背景色 (Background) | 象牙白 | `#FFFFF0` |
| 文本色 (Text) | 深灰 | `#333333` |

### 方案二：活力校园 (Vibrant Campus)

此方案采用明亮的青色和橙色，充满活力与创造力，适合用于展示创新教学或学生活动的报告。

| 用途 | 颜色 | HEX 色值 |
| :--- | :--- | :--- |
| 主色 (Primary) | 活力青 | `#20B2AA` |
| 辅助色 (Secondary) | 浅灰 | `#E0E0E0` |
| 强调色 (Accent) | 阳光橙 | `#FFA500` |
| 背景色 (Background) | 纯白 | `#FFFFFF` |
| 文本色 (Text) | 石墨灰 | `#4A4A4A` |

### 方案三：现代启蒙 (Modern Enlightenment)

以柔和的蓝灰色为主调，搭配薄荷绿，体现了现代教育的科技感与人文关怀，风格冷静、清晰。

| 用途 | 颜色 | HEX 色值 |
| :--- | :--- | :--- |
| 主色 (Primary) | 蓝灰 | `#778899` |
| 辅助色 (Secondary) | 淡雅银 | `#F2F3F4` |
| 强调色 (Accent) | 薄荷绿 | `#98FF98` |
| 背景色 (Background) | 白烟 | `#F5F5F5` |
| 文本色 (Text) | 碳黑 | `#2C2C2C` |
