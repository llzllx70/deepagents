# HTML 幻灯片设计师

本技能旨在指导 Manus 生成专业、美观且符合演示设计最佳实践的 HTML 幻灯片（PPT）。请严格按照以下工作流程执行。

## 核心工作流程

### 步骤 1: 分析内容并确认页数

在开始设计之前，首先需要确定演示文稿的页数。

1.  **检查用户输入**: 检查用户是否在需求中明确指定了幻灯片的页数。
2.  **分析并建议**: 如果用户没有指定页数，请根据用户提供的内容大纲，分析其结构和信息量，预估一个合理的页数范围。**注意：宁可多页也不要在一页中塞入过多内容**。每页只承载一个核心观点。
3.  **向用户确认**: 将预估的页数或页数范围提供给用户，并请求确认。只有在用户确认后才能继续下一步。

> **示例提问 (如果用户未指定页数):**
> "根据您提供的内容，我分析后建议将演示文稿设计为 8-10 页。其中包含 1 页封面，1 页目录，5-7 页核心内容（交替使用卡片页、数据页、两栏页等不同版式），以及 1 页结束页。您是否同意这个页数安排？"

### 步骤 2: 明确行业并提供设计方案

在页数确定后，为幻灯片选择合适的视觉风格。

1.  **检查用户偏好**: 检查用户是否已经指定了偏好的设计风格或配色方案。如果已指定，则直接进入步骤 3。
2.  **确定行业**: 如果用户未指定风格，请根据内容确定所属的行业领域（如：科技、金融、教育等）。
3.  **读取配色库**: 使用 `file` 工具读取 `/home/ubuntu/skills/html-ppt-designer/references/color_palettes.md` 文件。
4.  **呈现选项**: 从配色库中找到对应行业的章节，选择 **三种** 风格各异的方案，以清晰的格式呈现给用户，让用户做出选择。不能自行决定。

> **示例提问:**
> "为了让您的演示文稿更具专业性，我根据您提到的'金融'行业，推荐以下三种设计风格，请选择您偏好的一种：
> 
> 1.  **财富金蓝**: 经典的金色与深蓝色结合，象征财富与信任，风格稳健、专业。
> 2.  **现代黑金**: 以哑光黑为主调，搭配精致的金色点缀，风格高端、现代。
> 3.  **稳健蓝灰**: 以沉稳的蓝灰色为主调，传递出专业、理性和可靠的感觉。"

### 步骤 3: 规划内容分页

在生成代码之前，**必须先规划每一页的内容分配**，确保不会出现单页内容超载。

1.  **读取设计指南**: 使用 `file` 工具读取 `/home/ubuntu/skills/html-ppt-designer/references/design_guidelines.md` 文件。
2.  **重点阅读第 4 章"内容量硬性约束"**: 了解每种版式的元素数量上限。
3.  **逐页规划**: 将用户的内容分配到每一页中，确保每页的内容量不超过对应版式的硬性上限。如果某个主题的内容超出单页限制，**必须拆分为多页**。
4.  **常见拆分场景**:
    *   需要展示 6+ 个并列项目（如岗位、产品、功能）→ 拆分为 2 页卡片网格，每页最多 4 张卡片
    *   统计数据 + 详细说明 → 第 1 页放统计卡片，第 2 页放说明列表
    *   大量要点（6+ 个）→ 拆分为 2 页标准内容页

### 步骤 4: 应用设计规范生成幻灯片

根据步骤 3 的分页规划，严格遵循设计规范生成代码。

1.  **严格遵守规范**: 在编写代码时，必须严格遵守 `design_guidelines.md` 中定义的所有规范，包括但不限于：
    *   **固定尺寸布局**: 必须使用 `25.4cm` x `14.29cm` 的固定物理单位定义幻灯片容器。禁止使用 `vw`、`vh`、`%` 等相对单位定义容器尺寸。
    *   **CSS变量系统**: 必须使用 `:root` 中定义的CSS变量来统一管理颜色、间距、字体，将用户选择的配色方案替换到变量中。必须包含 `--footer-reserve: 56px` 变量。
    *   **版式多样性**: 必须交替使用不同版式（封面、目录、章节过渡、卡片网格、两栏对比、数据统计、引用、结束页），创造视觉节奏感，避免所有页面使用相同布局。
    *   **内容量硬性约束（最高优先级）**: 严格遵守设计指南第 4 章的硬性数量限制。卡片网格最多 4 张（wrap 布局），统计页禁止在卡片下方添加额外内容，标准内容页最多 5 个要点。**违反此规则会导致 PDF 导出时内容溢出和重叠。**
    *   **页脚预留空间**: `.slide` 的 `padding-bottom` 必须使用 `calc(var(--s-2xl) + var(--footer-reserve))` 为页脚预留空间。封面页和结束页没有页脚，需用 `.slide.cover, .slide.end { padding-bottom: var(--s-2xl); }` 覆盖。
    *   **防溢出CSS机制**: 所有 flex 布局的内容容器必须设置 `min-height: 0`。卡片描述文字必须使用 `-webkit-line-clamp: 2` 限制为最多 2 行。
    *   **分页控制**: 每一页幻灯片内容必须完整显示，不能被分页截断。打印样式中必须包含 `page-break-after: always; break-after: page; page-break-inside: avoid; break-inside: avoid;`。
    *   **页面尺寸声明**: `@page { size: 25.4cm 14.29cm; margin: 0; }` 必须作为**顶层CSS规则**声明，禁止嵌套在 `@media print` 内部。
    *   **装饰元素**: 适当使用渐变背景、半透明几何圆、色条装饰、标签胶囊等纯CSS装饰手法提升设计感。

### 步骤 5: 自检并交付

生成代码后，**必须逐页执行自检清单**（见 design_guidelines.md 第 4.4 节），确认每一页都符合内容量限制。只有全部通过自检后，才能交付给用户。
