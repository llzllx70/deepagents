# 匹配度评分规则

匹配度用于排序与推荐，建议按 0-100 打分。可按以下权重计算：

- 技能匹配度（40%）：简历技能与岗位技能要求的覆盖程度
- 经验匹配度（20%）：应届/实习/1年以内优先
- 目标城市匹配度（15%）：是否在候选人目标城市或可接受范围
- 薪资匹配度（15%）：是否达到期望区间或市场合理区间
- 行业/岗位一致度（10%）：岗位名称、业务方向是否符合目标

## 快速打分法

对每一项打 0-100 分，按权重加权求和后四舍五入。

```
match_score = skill*0.4 + exp*0.2 + city*0.15 + salary*0.15 + role*0.1
```

## 评分说明

- 技能匹配：命中核心技能 80+，仅命中通用技能 50-70。
- 经验匹配：应届/实习 90+，1-3年 70-85，3-5年 50-65。
- 城市匹配：目标城市 100，可接受城市 70，否则 40。
- 薪资匹配：达到期望上限 90+，略低 70-85，不匹配 50 以下。
- 岗位一致：同岗位名称/方向 90+，相近方向 70-85，跨度大 50-65。

若存在明显硬性门槛（例如学历不符），可额外扣 10-30 分。
